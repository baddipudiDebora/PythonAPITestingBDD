Petstore API Test Suite (Behave for BDD + Python API testing Request library)
CI License: MIT Cypress Node.js

This project is designed to validate the core functionality of the Petstore's RESTful endpoints including pets, store, and users. It has a BDD layer (Behave) wrapped on Python API request.
